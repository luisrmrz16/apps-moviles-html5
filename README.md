# Apps móviles HTML5

Página web básica creada con HTML5 semántico sobre los tipos de aplicaciones
móviles (nativas, web e híbridas) y los sistemas operativos Android y iOS.

🔗 **Ver en línea:** https://luisrmrz16.github.io/apps-moviles-html5/

## Contenido

- Tipos de aplicaciones móviles
- Sistemas operativos móviles
- Referencias en formato APA

## Etiquetas HTML5 utilizadas

`head`, `title`, `header`, `hgroup`, `h1`, `h2`, `nav`, `ul`, `li`, `main`,
`section`, `article`, `p`, `figure`, `img`, `figcaption`, `footer`

## Cómo verlo

Abre `index.html` en cualquier navegador; no requiere instalación.
