Tipos de aplicaciones móviles

Nativas, web e híbridas

Existen tres tipos principales de aplicaciones móviles:

  • Nativas: se programan para un solo sistema operativo, como Android o iOS, y pueden acceder a las capacidades del dispositivo mediante las API de la plataforma y los permisos correspondientes.
  • Web: se abren desde el navegador y se hacen con HTML, CSS y JavaScript (Mozilla, s.f.). Funcionan en cualquier plataforma que tenga un navegador, sin instalarse desde una tienda.
  • Híbridas: se desarrollan con HTML, CSS y JavaScript y se ejecutan dentro de un contenedor nativo. Herramientas como Ionic y Capacitor permiten compartir gran parte del código entre Android y iOS (Ionic, s.f.).

Flutter y React Native también permiten desarrollar aplicaciones para varias plataformas, pero no son ejemplos de aplicaciones híbridas basadas en tecnologías web dentro de un contenedor nativo (Google, s.f.; Meta Platforms, s.f.).

Sistemas operativos móviles

Android y iOS

Android, impulsado por Google, se utiliza en muchas marcas de teléfonos. Su base, Android Open Source Project (AOSP), es de código abierto; los servicios de Google y algunos componentes de los fabricantes son propietarios (Android Open Source Project, s.f.). Sus apps se pueden desarrollar en Android Studio con Kotlin o Java (Android Developers, s.f.).

iOS, de Apple, es el sistema operativo del iPhone. Es un sistema propietario que incorpora aislamiento de aplicaciones y control de permisos para proteger los datos y los recursos del dispositivo (Apple, s.f.-a). Sus apps se pueden desarrollar en Xcode con Swift u Objective-C (Apple, s.f.-b).
